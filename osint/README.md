# OSINT & Digital Forensics

Authorised public-source intelligence and forensic research toolkit.

## Scope

- Public-source identity resolution
- Alias and username correlation
- Public employment and business records
- ABN/ACN research
- Public court and tribunal records
- News and historical archive research
- Public social-media research
- Domain and infrastructure reconnaissance
- Certificate-transparency research
- DNS/RDAP/WHOIS research
- Public GitHub research
- Evidence preservation
- Timeline reconstruction
- Source correlation and confidence assessment

## Evidence Workflow

RAW LEAD
→ IDENTITY ATTRIBUTES
→ INDEPENDENT SOURCE
→ CROSS-CORRELATION
→ TIMELINE CHECK
→ CONTRADICTION CHECK
→ CONFIDENCE SCORE
→ EVIDENCE RECORD

## Operating Principle

Public/passive reconnaissance by default.

Active security testing is performed only against systems for which explicit authorisation exists.

## Evidence Record

Each significant finding should record:

- Evidence ID
- Source
- URL
- Publication date
- Access date/time
- Claim
- Matching identity attributes
- Independent corroboration
- Contradictions
- Source quality
- Confidence
- SHA-256 hash where evidence is preserved
